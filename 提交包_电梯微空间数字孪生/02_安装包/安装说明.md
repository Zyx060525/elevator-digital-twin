# 安装包说明（离线依赖 wheel）

本目录是**离线安装包**：把作品运行所需的全部 Python 依赖预先下载成 `*.whl`，
评审机在没有外网的情况下也能一键装好。

---

## 一、内容

| 文件 / 目录 | 说明 |
|---|---|
| `一键安装_Windows.bat` | Windows 一键安装（离线） |
| `一键安装_Linux.sh` | Linux 一键安装（离线） |
| `requirements-lock-windows.txt` | Windows 用**锁定版本**清单（与 `wheels_windows_py311/` 一一对应） |
| `requirements-lock-linux.txt` | Linux 用**锁定版本**清单（与 `wheels_linux_py311/` 一一对应，含 gunicorn） |
| `wheels_windows_py311/` | Windows x64 + CPython 3.11 的 wheel（110 个文件，97.6 MB，最大单文件 12.3 MB） |
| `wheels_linux_py311/` | Linux x86_64 + CPython 3.11 的 wheel（106 个文件，99.4 MB，最大单文件 16.0 MB） |

> 所有 wheel 均为**官方 PyPI 原包**，未做任何修改；版本与作者本机已验证可运行环境完全一致，
> 并已在**全新虚拟环境**中用 `--no-index` 纯离线安装成功、跑通 13 项测试样例（ALL PASS）。
> 单个文件最大 16 MB，远小于 200 MB 限制。

---

## 二、怎么用

### Windows

```bat
cd 02_安装包
一键安装_Windows.bat
```

等价命令（可手工执行）：

```bat
python -m pip install --no-index --find-links wheels_windows_py311 -r requirements-lock-windows.txt
```

### Linux

```bash
cd 02_安装包
bash 一键安装_Linux.sh
```

等价命令：

```bash
python3 -m pip install --no-index --find-links wheels_linux_py311 -r requirements-lock-linux.txt
```

> `--no-index` 表示**完全不访问网络**，只用本目录里的 wheel；
> `--find-links` 指定 wheel 所在目录。装完即可直接运行作品。

## 三、想用联网安装？

```bash
cd ../01_代码
python -m pip install -r requirements.txt      # 不锁版本的宽松清单
```

---

## 四、平台/版本不匹配怎么办？

离线 wheel 是 **CPython 3.11 + x64**（Windows）与 **CPython 3.11 + x86_64**（Linux）：
- 如果评审机是 Python 3.10/3.12，pip 会报 “no matching distribution”，此时请用**联网安装**；
- 如果是 macOS / ARM（Apple Silicon、aarch64），同样请用联网安装；
- 只要 Python 是 3.11 且系统是 x64/x86_64，离线包 100% 可用（已实测全新虚拟环境安装成功）。
