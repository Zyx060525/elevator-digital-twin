# 运行说明

> 作品：**电梯微空间数字孪生：社交距离与交流行为耦合的多智能体仿真与治理优化**
> 适用：Windows / Linux；Python 3.11（3.10 / 3.12 亦可，见第 7 节排错）

本说明按「环境 → 安装 → 运行 → 验证 → 排错」顺序编排，照抄命令即可跑通全部内容。

## 4. Web 前端使用（入口 5）

启动后浏览器访问 **http://127.0.0.1:5000**：

1. **参数面板**：轿厢宽/高、乘客数、交流意愿、舒适距离、交流范围/阈值、步数、随机种子；
2. **空间热力网格**：颜色 = 最近邻距离，P=普通乘客、C=交流中；支持**逐步回放**（快照帧）；
3. **指标卡片 + 指标曲线**：平均最近邻距离 / 违规率 / 交流对数随步变化；
4. **批量实验**：交流意愿 × 乘客数 → 对比表格 + 对比图；
5. **Agnes 智能分析**：调用 Agnes 模型输出分析与治理策略（需 Key，见第 5 节）。

后端接口（可用 curl / Postman 直接验证，测试样例见 `04_测试样例`）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查，返回 `{"status":"ok","agnes_ready":false}` |
| POST | `/api/simulate` | 单次仿真（基础版） |
| POST | `/api/simulate_enhanced` | 单次仿真（增强版，单位：米） |
| POST | `/api/sweep` | 批量实验（返回表格 + 对比图 base64） |
| POST | `/api/agnes` | Agnes 分析（`mode=plan` 规划 / `mode=analyze` 分析） |

## 5. Agnes 模型 / AGH 闭环（核心亮点，含 Key 配置）

### 5.1 架构

```
AGH（Agnes Harness）
 ├─ ① 任务规划   → 调用 Agnes 模型（agnes-3.0-flash）拆解任务
 ├─ ② 能力调用   → 通过 MCP 协议调用 elevator-twin 工具
 │                 run_simulation / grid_snapshot / optimize_social_distance
 ├─ ③ 反馈处理   → 读取指标（违规率、交流对数）判断是否达标，调整参数再仿真
 └─ ④ 结果验证   → 输出密闭空间社交距离治理策略
```

命令行一键复现闭环：

```bash
cd 01_代码
python -m elevator_twin.agh_loop
```

### 5.2 配置 Agnes Key（二选一）

```bash
# 方式一：环境变量（推荐，不会写进文件）
set AGNES_API_KEY=你的Key            # Windows CMD
$env:AGNES_API_KEY="你的Key"         # Windows PowerShell
export AGNES_API_KEY=你的Key         # Linux / macOS

# 方式二：本地文件（该文件已被 .gitignore 忽略，切勿提交）
echo 你的Key > elevator_twin\.agnes_key
```

自检连通性：

```bash
python -m elevator_twin.agnes_client
# 期望输出：模型：agnes-3.0-flash / 连通性自检：连通正常
```

> **未配置 Key 也能完整验收**：`agnes_client.available()` 返回 False 时，
> AGH 闭环自动降级为确定性文本（仍完整走 MCP 调用链），仿真、Web 图表、测试样例均正常。
> 提交包内**不含任何密钥**。

## 7. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `'python' 不是内部或外部命令` | 未把 Python 加入 PATH | 重装 Python 勾选 Add to PATH，或用完整路径 |
| 离线安装报 `No matching distribution` | Python 不是 3.11 或系统非 x64 | 改用联网安装 `pip install -r requirements.txt` |
| 图表中文变方块 | 系统缺少中文字体 | Windows 自带微软雅黑即可；Linux 可 `apt-get install fonts-noto-cjk` |
| 网页能开但点按钮提示「连不上后端」 | 前端与后端不同域（Netlify 前端 + Render 后端） | 访问时加 `?api=https://你的后端域名` |
| `Agnes 调用失败，请检查 Key 与网络` | 未配置 Key / 网络不通 | 按 5.2 配置 Key；无 Key 时忽略该功能，其余功能不受影响 |
| `mcp` 导入报错 | mcp 1.x 与 2.x 模块名不同 | 代码已兼容：`mcp.server.fastmcp.FastMCP`（1.x）/ `mcp.server.mcpserver.MCPServer`（2.x） |
| Netlify 构建报 `mise ... python-3.11.0` | 仓库根目录 `runtime.txt` 用了 Render 格式 | 本项目已删除该文件，版本改用环境变量声明（见 `部署说明_Netlify_Render.md`） |

## 8. 关键文件与数据流

```
01_代码/
  elevator_twin/model.py            基础模型：Passenger 智能体 + ElevatorModel + 5 项指标
  elevator_twin/model_enhanced.py   增强模型：米制尺寸 + 楼层上下客 + 社会力势能移动
  elevator_twin/run.py              run_once() / sweep() —— Web 与命令行共用
  elevator_twin/visualize.py        4 张 PNG（figs/）
  elevator_twin/mcp_server.py       MCP 工具服务（stdio）
  elevator_twin/agh_loop.py         AGH 四步闭环（真实 MCP 客户端）
  elevator_twin/agnes_client.py     Agnes OpenAI 兼容客户端（Key 缺失自动降级）
  webapp.py                         Flask：/api/health|simulate|simulate_enhanced|sweep|agnes
  templates/index.html              前端单页（参数面板 / 回放 / 图表 / 批量实验 / Agnes）
  build_static.py                   静态站点构建（Netlify 部署用）
```

仿真数据流：
`参数 → ElevatorModel.step()（每步：解除/建立交流 → 移动决策）→ DataCollector 指标 → JSON/图表 → 前端或 AGH`。
