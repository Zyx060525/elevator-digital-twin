# 测试样例说明

本目录是「测试样例」四件套的第三部分，覆盖赛事要求的 **正常 / 边界 / 失败** 三类场景，
并额外提供 **Web 接口** 与 **MCP 工具** 两组可核查证据。**全部离线可跑**（不需要 Key、不需要联网）。

---

## 一、目录内容

| 文件 | 说明 |
|---|---|
| `run_samples.py` | **一键自检脚本**：跑完所有样例并自动与预期结果比对，输出 PASS/FAIL 汇总 |
| `一键自检_Windows.bat` / `一键自检_Linux.sh` | 双击/一条命令即可运行自检 |
| `输入样例/*.json` | 各样例的输入参数（可直接拿去复现） |
| `预期输出/*.json` | 预期结果（真实运行产物，含容差） |
| `_生成预期输出.py` | 【作者工具】由输入样例真实运行重建预期结果，评审无需执行 |
| `实际运行输出.txt` | 本机真实运行日志（留证） |

---

## 二、样例总览

### 1) 正常样例

| 编号 | 输入文件 | 场景 | 预期（关键指标） |
|---|---|---|---|
| N1 | `输入样例/N1_基础_正常.json` | 基础版 4×4、8 人、意愿 0.5、30 步 | avg_dist≈1.104、violation=1.0、chat_pairs≈3 |
| N2 | `输入样例/N2_批量_正常.json` | 交流意愿 × 乘客数 5×3 组合 | 15 行对比表，与 `预期输出/N2_批量_正常.json` 一致 |
| N3 | `输入样例/N3_增强版_正常.json` | 增强版：1.6m×1.4m、6 层、上下客、社会力 | avg_dist≈0.53m，远小于 1.0m 标准社交距离（核心洞察） |

### 2) 边界样例

| 编号 | 输入文件 | 场景 | 预期（关键指标） |
|---|---|---|---|
| B1 | `输入样例/B1_满载边界.json` | 4×4、16 人 = 容量上限，无空闲格 | 不崩溃；乘客保持原位；violation_rate=1.0 |
| B2 | `输入样例/B2_零意愿边界.json` | 交流意愿均值 0.0 | chat_pairs 恒为 0（只剩社交距离最大化生效） |
| B3 | `输入样例/B3_单人边界.json` | 仅 1 名乘客 | avg_nearest_distance=0、violation_rate=0、chat_pairs=0，不报错 |

### 3) 失败样例（期望抛出可读异常，不静默失败）

| 编号 | 输入文件 | 场景 | 预期 |
|---|---|---|---|
| F1 | `输入样例/F1_容量超限.json` | 4×4 放 17 人 > 容量 16 | `ValueError`，信息含「容量」 |
| F2 | `输入样例/F2_非法人数.json` | n_passengers = -1 | `ValueError`，信息含「负数 / 不能为负」 |

### 4) 接口 & MCP 样例

| 编号 | 内容 | 预期 |
|---|---|---|
| A1 | `GET /api/health`（Flask 测试客户端，无需起服务） | 200，`{"status":"ok","agnes_ready":bool}` |
| A2 | `POST /api/simulate`（参数同 N1） | 200，返回 `metrics/grid/frames/curve` 四个字段 |
| A3 | `POST /api/sweep` | 200，返回 `table`（15 行）+ `plot`（base64 PNG） |
| M1 | MCP 工具清单 | 含 `run_simulation`、`grid_snapshot`、`optimize_social_distance` |
| M2 | MCP `optimize_social_distance(n_passengers=8, steps=30)` | 返回 low/mid/high 三档指标，high 的交流对数 > low 的交流对数 |

## 三、怎么跑

```bash
cd 04_测试样例
python run_samples.py                          # 全量自检（13 项）
python run_samples.py --verbose                # 打印每个样例的详细指标 + 空间快照
python run_samples.py --only N1 F2             # 只跑指定样例
python run_samples.py --verbose --log 运行日志.txt   # 同时写 UTF-8 日志（Windows 重定向防乱码）
```

输出示例（本机真实结果，完整日志见 `实际运行输出.txt`）：

```
[PASS] N1  avg_dist=1.104 min_dist=1.000 violation=1.000 chat_pairs=3（5 项指标均在 0.05 容差内）
[PASS] N2  15/15 行全部一致：平均距离 3.0（4 人 / 意愿 0.2） → 1.0（8 人 / 意愿 0.8），交流对数 0 → 5
[PASS] F1  按预期抛出 ValueError：乘客数 17 超过轿厢容量 16
[PASS] A2  POST /api/simulate → 200：metrics 一致、grid 4×4（8 名乘客）、frames 31 帧
[PASS] M2  低意愿：距离 1.2803 / 0 交流对 → 高意愿：距离 1.0 / 4 交流对
------------------------------------------------------------------------------
共 13 项：通过 13，失败 0，跳过 0
ALL PASS
```

退出码：0 = 全部通过；1 = 有失败项（便于 CI / 自动判分调用）。

## 四、容差与确定性说明

- 模型使用 `seed`（默认 42）固定随机数，**同版本依赖下结果完全可复现**；
  浮点指标比对容差为 **0.05**（跨依赖小版本差异时仍能通过）。
- `预期输出/*.json` 由本包代码在本机 Python 3.11 + mesa 2.4.0 环境真实运行生成，
  与 `02_安装包` 内锁定版本一致。
- 无 Agnes Key 时，`/api/agnes` 不在自检范围内（需要联网），其余全部离线可跑。
