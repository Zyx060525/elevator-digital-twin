## 三、本机没有 Chrome / Edge 时，手动截图方法（Windows）

1. 进入 `01_代码`，执行 `python webapp.py`，浏览器打开 http://127.0.0.1:5000
2. 点「▶ 运行仿真」，等指标卡与曲线出来 → 按 **Win + Shift + S**（系统截图工具）框选 → 保存 PNG
3. 截**整页**：Chrome / Edge 里按 F12 → `Ctrl + Shift + P` → 输入 `Capture full size screenshot` → 回车
4. 截**命令行日志**：PowerShell 里先执行 `$env:PYTHONIOENCODING='utf-8'`，再
   `python -m elevator_twin.agh_loop | Tee-Object AGH执行记录.txt`，然后用 Win+Shift+S 截窗口；
   若只想留证不截图，直接用 `.txt` 日志即可（本目录已提供）。

## 五、顺带修掉的一个真实缺陷（已复现并验证）

- **现象**：网页首屏样式正常，但页面下方出现一大片 JS 源码文本，且「运行仿真」按钮点了没反应。
- **原因**：`01_代码/templates/index.html` 第 384 行的 JS 注释里写了字面的 `</script>`。
  HTML 解析器在「脚本数据」状态下遇到 `</script` 就会**提前结束脚本块**（写在注释里也算），
  其后的 JS 被当成普通文本显示，`runSimulate / runSweep / runAgnes / renderGrid / switchModel`
  等函数因此根本没有定义。
- **修复**：该注释改为 `<\/script>`（加反斜杠）并补充说明，避免后续再踩；
  `public/index.html` 由 `python build_static.py` 重新生成（与 `templates/index.html` 一致）。
- **验证**：见 `06_前端功能自检.png` —— 页面无源码泄漏 = yes；五个函数均为 `function`；
  真实调用 `runSimulate()` 后指标卡渲染成功、曲线为 PNG dataURL、回放标签显示「第 30 步」。
