## 三、作品详情（详细描述作品内容、实现方案、核心功能与技术亮点）

```
【作品内容】
把电梯轿厢这个「高密度、短时、密闭」的微空间做成可计算、可复现的数字孪生，用多智能体模拟乘客的移动—避让—交流，回答两个问题：电梯里社交距离到底能不能维持？交流行为又会怎样反向压缩空间距离？
项目含双模型：基础版把轿厢离散为 4×4 网格（可调），基于 MESA 建模 8 名乘客，按社交距离偏好相互排斥、按交流意愿结对攀谈；增强版改用真实轿厢尺寸 1.6m×1.4m（格长 0.4m），加入楼层、到站间隔、上下客与社会力（排斥/吸引），贴近真实乘梯过程。
输出四类可解释指标：平均最近邻距离、最小最近邻距离、社交距离违规率（<1m 占比）、交流对数与交流对平均距离。

【实现方案】
1) 仿真内核：Python 3.11 + MESA 2.4.0，随机激活顺序与随机种子全可复现（seed=42 逐位复现）。
2) 能力封装：用 MCP（Model Context Protocol）把仿真标准化为 3 个工具——run_simulation（跑一次并回指标）、grid_snapshot（返回空间快照）、optimize_social_distance（低/中/高三档交流意愿对比），供智能体"像调工具一样调仿真"。
3) AGH 执行闭环：Agnes Harness 负责 ①任务规划 →②MCP 能力调用 →③反馈处理（读指标、判断是否达标、不达标就调参重跑）→④结果验证，四步均有可逐条核查的日志与留证截图。
4) 大模型：全程仅调用 Agnes（agnes-3.0-flash），经 OpenAI 兼容 Chat Completions 接口（https://api.agnes-ai.cn/v1）接入，不接任何第三方模型；Key 只通过环境变量/本地文件配置、绝不入库，未配置 Key 时自动降级为确定性文本，演示不中断。
5) 交互前端：Flask 提供 /api/health、/api/simulate、/api/sweep 接口，单页界面支持参数调节、空间快照逐帧回放、指标曲线、批量实验对比表与「Agnes 智能分析」；页面内置与 Python 后端逐位一致的 JS 引擎，因此在 Netlify 这类纯静态托管（没有后端）也能完整跑出仿真、图表与对比表。
6) 交付形态：源码 + Windows/Linux 离线 wheel 安装包（一键脚本，全新虚拟环境纯离线安装即可复跑）+ 运行说明 + 13 项测试样例（正常/边界/失败/接口/MCP）+ 6 张证据图与留证日志。

【核心功能】
参数化仿真（网格尺寸、乘客数、交流意愿、舒适距离、步数、种子）；增强版真实尺寸与楼层上下客；空间快照逐帧回放（红=拥挤 / 绿=宽松）；指标曲线与热力图；「交流意愿 × 乘客数」批量对比实验（一次 15 组）；Agnes 策略解读与治理建议；一键自检 13 项；一键生成证据材料。

【技术亮点】
① 新视角：把"交流行为"作为主动社交变量纳入社交距离模型，量化其对空间距离的压缩效应。
② 硬结论：在真实电梯尺寸下，即使乘客彼此最大化距离，平均最近邻距离也只有约 0.533m（最小 0.4m），社交距离违规率恒为 1.0（100%）——证明密闭空间的社交距离在物理上不可达；而交流行为会在此基础上进一步压缩距离（低交流意愿：0 交流对、平均 1.280 → 高交流意愿：4 交流对、平均 1.0）。
③ 真闭环：用 MCP 把仿真能力标准化封装，让 Agnes 像调用工具一样调用仿真，形成"模型—工具—验证"的执行闭环，调用链（initialize → list_tools → call_tool×3）可逐条核查。
④ 真一致：前端内置 JS 引擎逐位复刻了 CPython 的 MT19937 随机数与 MESA 随机激活顺序，87 组用例与 Python 后端逐字段一致；真实浏览器端到端三场景 57/57 通过、线上纯静态站点 9/9 通过——静态托管下不报错、不空白。
⑤ 可离线：全流程无网可跑（离线 wheel 安装包 + 无 Key 自动降级），且通过 13/13 自检，评审环境零障碍复现。

【应用价值】
治理层面可直接回答"电梯里该鼓励还是抑制寒暄、同乘人数如何限制"；方案可迁移到地铁车厢、候机厅、教室等密闭/半密闭空间，并可通过摄像头/闸机接入真实人流数据做"仿真—现实"同化，向可治理的数字孪生演进。
```

> 字数约 1500 字；若表单限制更短，优先保留【技术亮点】②③④与【实现方案】第 2、3 条（这几条是评审最看重的差异化）。
