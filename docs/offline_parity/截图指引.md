# 手动截图指引（自己点、自己截，不用脚本渲染）

> 本文件只给「怎么截」的步骤，**不生成任何图片**。
> 本目录下的 `e2e_page.py` / `e2e_online.py` 也**默认不截图**（只有显式加 `--shot` 才会写 PNG），
> 仓库里现存的 4 张 PNG 是 2026-10-14 首次验证时的留证图，不会被后续运行覆盖。
> 截图的判定口径：每张图里必须能看清 **① 引擎徽章 ② 指标卡片 ③ 空间快照网格 ④ 指标曲线**。

## 零、准备工作

| 项目 | 做法 |
| --- | --- |
| 浏览器 | Chrome 或 Edge，窗口最大化（页面是三栏布局，宽度 ≥ 1600 才不折行） |
| 缩放 | 保持 100%（`Ctrl` + `0` 重置） |
| 整页截图 | `F12` → `Ctrl` + `Shift` + `P` → 输入 `Capture full size screenshot` → 回车（**截前先把 F12 面板关掉**，否则面板会占位；嫌麻烦就截完再裁掉底部） |
| 局部截图 | `Win` + `Shift` + `S` 框选 |
| 存图格式 | PNG，名字见第三节表格 |

## 一、图 A：线上站点（最省事，一张就够证明「纯静态托管也能跑」）

1. 打开地址：**https://elevator-digital-twin.netlify.app/**
2. 看左侧「引擎状态」那行徽章：先是灰色 **`检测中…`**，**约 3~5 秒后变成橙色 `浏览器内置引擎（离线）`**
   —— 这就是「Netlify 上没有 Python 后端 → 自动降级」的关键证据，**徽章必须出现在截图里**。
3. 点 **`▶ 运行仿真`**。
4. 等右侧出现（约 1~2 秒）：
   - 指标卡：`📏 1.104格 平均最近邻距离`、`📐 1格 最小最近邻距离`、`⚠️ 100.0% 社交距离违规率`、`💬 3 交流对数`、`↔️ 1格 交流对平均距离`
   - 空间快照：**4×4 = 16 个格子，其中 8 个写 `P`**
   - 回放条显示 **`第 30 步`**
   - 指标曲线：粉色折线图（2 张子图）
5. 再点 **`批量实验（对比表）`**，等下方出现 **15 行**对比表（w=0.2 / 0.4 / 0.8 × 5 个乘客数）；这张可以单独再截一张。
6. 整页截图 → 保存。

> 判定：指标数字必须和上面对得上（这组数字 = Python 后端 N1 用例的逐字输出，说明内置引擎没跑偏）。

## 二、图 B：增强版

1. 同一页面点 **`增强版 · 真实尺寸+上下客`** 标签（不用刷新）。
2. 点 **`▶ 运行仿真`**。
3. 期望：`📏 0.533m`、`📐 0.4m`、`⚠️ 100.0%`、`💬 2 交流对数`、`👥 6人 当前乘客数`、`🏢 6层 当前楼层`；网格变成 4×3 并有 `🏢 当前楼层 1 · 停靠 1` 的说明行。
4. 整页截图。

## 三、图 C：本机 Flask（证明「同源 Python 后端引擎」这条路径）

```powershell
cd 提交包_电梯微空间数字孪生\01_代码
python webapp.py
```
1. 浏览器打开 **http://127.0.0.1:5000**
2. 徽章这次应显示绿色 **`Python 后端引擎`**，提示行显示「已连接 Python 后端…」。
3. 点 `▶ 运行仿真` → 指标卡/网格/曲线应和图 A 完全一致（同一个引擎口径）。
4. 截整页。
5. 截完按 `Ctrl` + `C` 停掉服务。

## 六、每张图的「合格线」自查

- [ ] 徽章文字看得清（`浏览器内置引擎（离线）` 或 `Python 后端引擎`），不是 `检测中…`
- [ ] 指标卡片 4~6 个都完整，数字没被截断
- [ ] 网格里能看到 `P` / `C` / 空位，颜色有红绿深浅差异
- [ ] 曲线图不是空白框
- [ ] 页面底部**没有**大段 JS 源码泄漏（有的话说明 html 被改坏了）
